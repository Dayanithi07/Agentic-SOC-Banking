================================================================================
PRODUCT OVERVIEW
================================================================================

The product is NOT

❌ SIEM

❌ UEBA

❌ PAM

❌ SOAR

❌ SOC

❌ Chatbot

The product IS

✅ Agentic SOC Copilot

It acts as an AI Investigation Layer that integrates with existing banking security products.

It consumes telemetry from enterprise security systems, correlates events using collaborative AI agents, detects privileged access misuse and insider threats, performs explainable reasoning and generates investigation-ready incident reports for SOC analysts.

The SOC analyst always remains the final decision maker.

================================================================================
PROJECT GOAL
================================================================================

Build an enterprise-grade Agentic SOC Copilot that assists Security Operations Center (SOC) analysts by transforming hundreds of isolated security alerts into one explainable investigation report.

The system should

• Detect privileged account misuse

• Detect insider threats

• Perform behavioural analysis

• Correlate events across multiple security domains

• Produce explainable reasoning

• Generate investigation-ready reports

• Recommend response actions

• Reduce alert fatigue

The platform must integrate with existing banking security infrastructure instead of replacing it.
